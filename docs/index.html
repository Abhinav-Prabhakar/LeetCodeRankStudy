What this is (and isn’t)

LeetCode has no public leaderboard for the profile “Rank” shown under your username. The only enumerable public list is the contest leaderboard, whose nodes expose each user’s profile rank. I scanned 4,500 contest profiles (pages 1–180 of globalRanking) and kept every user whose profile rank was ≤ 2,000, then fetched their live solved totals from matchedUser.submitStatsGlobal. That yields the 243 real users below. It is a sample of ranks 1–1,983, not a complete census: users who never joined a contest are invisible to this method.

The shape is consistent with LeetCode’s definition: profile rank is driven by problems solved, while the separate “Global Ranking” on the profile is contest rating. At the very top the solved count saturates at 4,123 (the whole problem set), so ties there are effectively arbitrary.
